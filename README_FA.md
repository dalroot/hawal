**هه‌واڵ** (Hawal - در زبان کُردی به‌معنای *«همراه، دوست یا پیام‌رسان»*) پاسخی مهندسی و مدرن به چالش‌های پیچیده ارتباطات برون‌مرزی و اختلالات زیرساختی شبکه است. این سامانه تمام پیکربندی‌ها، کلیدهای ارتباطی و تله‌متری زنده را در یک کنترل‌پنل تحت‌وب متمرکز مدیریت کرده و به‌صورت آنی (Real-Time) به ایجنت‌های سبک روی سرورهای لبه (Edge) همگام‌سازی می‌نماید.

🌐 **زبان‌ها:** [English Documentation](README.md) | **فارسی** | 💬 **جامعه تلگرام:** [t.me/dallrep](https://t.me/dallrep)

## ✨ قابلیت‌ها و نقاط قوت کلیدی

- &rlm;🌐 **کنترل‌پنل مدرن با معماری Ant Design:** محیط کاربری یکپارچه، واکنش‌گرا و سریع بدون نیاز به رفرش صفحه با تم‌های تیره و روشن ارگونومیک.
- &rlm;⚡ **اتصال خودکار و بدون دخالت نودها (Zero-Touch):** استقرار ایجنت با یک دستور `curl` اختصاصی بدون نیاز به انتقال دستی فایل یا تنظیمات SSH.
- &rlm;🚀 **چهار هسته مستقل و قدرتمند ارتباطی:**
  - &rlm;• **هسته بومی هوال (Hawal Core v2.5.1):** موتور سیستمی نوشته‌شده به زبان Go، مجهز به پکت‌های خام لینوکس (Raw-TCP)، فیلترهای بسته درون کرنل (cBPF/eBPF)، رمزنگاری مدرن Noise PFS و مکانیزم رفع فریز صبحگاهی.
  - &rlm;• **هسته Backhaul:** برقراری تانل‌های مالتی‌پلکس پرسرعت هم‌روند روی بستر وب‌سوکت، TCP و TLS.
  - &rlm;• **هسته Paqet:** دستکاری مستقیم پکت‌های خام لایه چهار و الگوریتم کنترل ازدحام KCP جهت عبور از مسیرهای دارای افت شدید بسته (Packet Loss).
  - &rlm;• **هسته GOST v3:** رله چندپروتکلی امن با پشتیبانی هم‌زمان از ترافیک TCP و UDP (سازگار کامل با پروتکل‌های بر پایه QUIC نظیر هایستریا).
- &rlm;📊 **تله‌متری دقیق و زنده:** نمایش بلادرنگ مصرف پردازنده، حافظه رم، پهنای باند لحظه‌ای، پینگ، پکت‌لاس و اتصال فعال نودها.
- &rlm;📈 **محاسبه دقیق ترافیک از کرنل سرور مقصد:** خواندن ترافیک فیزیکی واقعی پکت‌های خام از جدول `raw` فایروال سرور خارج (محاسبه دقیق سربار پروتکل).
- &rlm;🛡️ **حفظ ۱۰۰٪ حریم خصوصی:** هسته هوال به هیچ وجه آی‌پی کلاینت‌ها یا اتصالات کاربران را ذخیره نمی‌کند و تنها رویدادهای سیستمی موتور را ثبت می‌نماید.
- &rlm;🪶 **سبک و بدون وابستگی سنگین:** پایگاه‌داده تعبیه‌شده SQLite بدون نیاز به نصب سرویس‌های سنگین مثل Redis یا PostgreSQL.

## 🏛️ معماری و توپولوژی شبکه

در معماری هوال، جریان مدیریت (Control Plane) به‌طور کامل از جریان انتقال ترافیک کاربران (Data Plane) مجزا است:

```text
       مرورگر مدیر شبکه
              │
              ▼
 ┌──────────────────────────┐        همگام‌سازی تنظیمات         ┌──────────────────────────┐
 │ پنل مستر هه‌واڵ (Master) │◄────────────────────────────────►│ نود خارج (Foreign Node)    │
 │ (FastAPI, SQLite, Web)   │        (هارت‌بیت امن هر ۳ ثانیه)  │ (/opt/hawal/agent.py)    │
 └──────────────────────────┘                                  └────────────┬─────────────┘
              ▲                                                             │
              │ همگام‌سازی                                                   │
 ┌────────────┴─────────────┐                                               │
 │ نود ایران (Iran Node)    │              کانال ارتباطی رمزشده هسته         │
 │ (/opt/hawal/agent.py)    │═══════════════════════════════════════════════╪═════════════════╗
 └────────────┬─────────────┘    (Hawal Core v2.5 / Backhaul / Paqet / GOST) │                 ║
              │                                                             ▼                 ║
              ▼                                                  سرویس مقصد (Xray, 3X-UI)     ║
      پورت ورودی در ایران                                         (فعال روی 127.0.0.1)         ║
      (مثلاً 443 یا 8443)                                                                     ║
```

## 🎛️ بررسی و مقایسه هسته‌های ارتباطی

| هسته ارتباطی | زبان و پایه | پروتکل‌های انتقال | رمزنگاری و امنیت | سناریوی پیشنهادی |
|---|---|---|---|---|
| **Hawal Core v2.5.1** | Go بومی | `rawpaq` (Raw-TCP) و `tls` و `tcp` | Noise X25519 (PFS) + ChaCha20-Poly1305 | **انتخاب اول و پیشنهادی**؛ مقاوم در برابر فیلترینگ شدید و بدون افت صبحگاهی |
| **Paqet Wire** | C / Go | پکت خام با الگوریتم KCP | کلید متقارن استاندارد | مسیرهای دارای پکت‌لاس بالا (نیازمند دسترسی root و عدم اشتراک پورت) |
| **Backhaul** | Go | `ws`، `tcp`، `tcpmux`، `tls` | TLS اختیاری | ترافیک‌های پرحجم با تعداد کانکشن بالا در بستر وب‌سوکت |
| **GOST v3** | Go | `tls`، `ws`، `kcp`، `quic` | رمزنگاری سفارشی چندپروتکلی | ترافیک‌های نیازمند رله UDP هم‌زمان و پروژه‌های Hysteria |

### ⚡ هسته اختصاصی هوال (Hawal Core v2.5.1)

هسته هوال بر مبنای آخرین پژوهش‌های امنیت شبکه و آزمایش‌های میدانی بازرسی عمیق بسته (DPI) توسعه داده شده است:

1. &rlm;🛡️ **حامل بومی Raw-TCP با فیلتر کرنل (`rawpaq`):** تولید مستقیم بسته‌های لایه ۴ با دستکاری پرچم‌های SYN/ACK بدون ردپای هندشیک معمول لینوکس، همراه با فیلترهای سبک cBPF در سوکت خام.
2. &rlm;🔄 **حل دائمی مشکل فریز صبحگاهی (Anti-Freeze & Deadlink Recovery):**
   - افزودن فریم کنترل دوطرفه `TypePong` (نوع رکورد ۹) جهت اعتبارسنجی زنده بودن رفت‌وبرگشت بستر فیزیکی.
   - پایش مداوم `lastInboundActivity`؛ در صورت بلک‌هولینگ یا افت خاموش مسیر توسط فیلترینگ (>۴۵ ثانیه بدون پاسخ)، نشست مسدودشده به شکل تمیز بسته شده و کلاینت فوراً ارتباطی تازه برقرار می‌کند.
   - اعمال مهلت زمانی ۱۰ ثانیه‌ای (`SetWriteDeadline`) روی ارسال سوکت‌ها، که امکان معلق ماندن یا قفل صف‌های KCP/Mux را به صفر می‌رساند.
3. &rlm;🔐 **امنیت رو به جلو (Perfect Forward Secrecy):** توافق کلید ناپایدار X25519 به ازای هر نشست و رمزنگاری احرازشده ChaCha20-Poly1305 به همراه پوشش‌دهی تصادفی طول فریم‌ها (Length Masking).
4. &rlm;🪶 **بهینه‌سازی منابع:** مصرف رم زیر ۲۰ مگابایت در نود ایران (حدود ۷۴٪ سبک‌تر از نمونه‌های سنتی پکت).

## 📋 پیش‌نیازهای استقرار و شبکه

### ۱. مشخصات سرورها
- **سیستم‌عامل:** اوبونتو ۲۰.۰۴ به بالا یا دبیان ۱۱ و ۱۲ (Ubuntu 22.04 / 24.04 LTS پیشنهاد می‌شود).
- **معماری پردازنده:** x86_64 (amd64) یا aarch64 (arm64).
- **حافظه رم:** حداقل ۵۱۲ مگابایت (۱ گیگابایت برای ترافیک‌های سنگین).
- **دسترسی:** کاربر روت (`root`) یا اختیارات `sudo`.

### ۲. پورت‌های فایروال
- **پورت پنل مستر:** پورت `9090` (یا پورت `443` در صورت استفاده از دامنه و SSL).
- **پورت هسته تانل:** پورتی دلخواه و آزاد روی سرور خارج (مانند `3107` یا `9999`) جهت تبادل دیتای تانل.
- **پورت فوروارد ورودی:** پورت‌هایی که کاربران به سرور ایران وصل می‌شوند (مانند `443` یا `8443`).

> ⚠️ **هشدار مهم:** شماره پورت هسته (Core Port) و پورت فوروارد شده نباید یکسان باشند.

## ⚡ نصب و راه‌اندازی سریع (دستور تک‌خطی)

### گام اول: نصب پنل مدیریت (Master Panel)

دستور زیر را در ترمینال سروری که می‌خواهید پنل وب روی آن قرار گیرد اجرا کنید:

```bash
curl -fsSL https://raw.githubusercontent.com/dalroot/hawal/master/install-panel.sh | bash
```

*(اختیاری: جهت تغییر پورت پیش‌فرض پنل از ۹۰۹۰ به پورت دیگر، می‌توانید از پارامتر `--port` استفاده کنید):*
```bash
curl -fsSL https://raw.githubusercontent.com/dalroot/hawal/master/install-panel.sh | bash -s -- --port 9090
```

پس از اتمام نصب، پنل از طریق مرورگر در دسترس خواهد بود:
`http://IP_SERVER:9090`

---

### گام دوم: اتصال هوشمند نودها (Zero-Touch Enrollment)

هیچ نیازی به دانلود یا ویرایش دستی فایل روی سرورها نیست:
1. در پنل وارد بخش **مدیریت نودها (Node Management)** شوید.
2. روی دکمه **افزودن نود** کلیک کرده و نام و نقش نود را مشخص کنید (`iran` یا `kharej`).
3. دستور `curl` اختصاصی تولیدشده را کپی و در ترمینال سرور مربوطه اجرا نمایید:

```bash
curl -fsSL "http://PANEL_IP:9090/install?token=YOUR_TOKEN&role=kharej&name=Germany" | bash
```

سرویس ایجنت به‌صورت خودکار در قالب `systemd` مستقر شده و وضعیت نود در پنل بلافاصله سبز (**Online**) می‌شود.

---

### گام سوم: راه‌اندازی اولین تانل

1. در پنل وارد منوی **مدیریت تانل‌ها (Tunnel Management)** شده و **ایجاد تانل جدید** را بزنید.
2. نود ایران و خارج را انتخاب کنید.
3. هسته تانل را بر روی **Hawal Stealth Core** (یا هسته دلخواه) قرار دهید.
4. پورت اختصاصی هسته (مثلاً `3107`) را وارد کنید.
5. پورت‌های سرویس ورودی و مقصد را مشخص نمایید (مثال: `443=127.0.0.1:443`).
6. روی **ذخیره و استقرار** کلیک کنید. تانل ظرف ۱ الی ۲ ثانیه برقرار و عملیاتی می‌گردد.

## 🐳 استقرار با Docker Compose

جهت اجرای مستقل پنل در قالب کانتینر داکر:

```bash
git clone https://github.com/dalroot/hawal.git
cd hawal
docker compose up -d --build
docker compose logs -f hawal-panel
```

## 🔒 امن‌سازی پنل با دامنه و گواهی رایگان SSL

توصیه می‌شود پنل وب را با اتصال دامنه و پروتکل امن HTTPS محافظت فرمایید:

```bash
# نصب Nginx و ماژول خودکار Let's Encrypt
sudo apt-get update && sudo apt-get install -y nginx certbot python3-certbot-nginx

# تنظیم ریورس پروکسی
sudo bash -c 'cat > /etc/nginx/sites-available/hawal << EOF
server {
    server_name panel.yourdomain.com;
    location / {
        proxy_pass http://127.0.0.1:9090;
        proxy_http_version 1.1;
        proxy_set_header Upgrade \$http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host \$host;
        proxy_set_header X-Real-IP \$remote_addr;
        proxy_set_header X-Forwarded-For \$proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto \$scheme;
    }
}
EOF'

sudo ln -sf /etc/nginx/sites-available/hawal /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
sudo certbot --nginx -d panel.yourdomain.com
```
