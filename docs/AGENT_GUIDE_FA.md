# 📖 راهنمای جامع ایجنت و نودهای هَوال (Hawal Agent Guide)

این راهنما برای اپراتورها و مدیران سرورهای خارج و نودهای واسط تدوین شده است تا بدون سردرگمی، سازوکار عملکرد ایجنت و تانل‌ها را درک کرده و در صورت نیاز عیب‌یابی کنند.

---

### ۱. اصل کارکرد ایجنت: همگام‌سازی خودکار و بدون دستکاری (Zero-Touch Sync)

* **نود خارج به هیچ‌گونه کانفیگ دستی تانل نیاز ندارد:**
  تمام تعاریف تانل، پورت‌ها و کلیدهای رمزنگاری در دیتابیس پنل مستر (سرور ایران) نگهداری می‌شوند.
* **سازوکار هماهنگی:**
  ایجنت نصب‌شده روی نود (`/opt/hawal/agent.py`) با توکن امنیتی منحصربه‌فرد خود، هر ۳ تا ۵ ثانیه با وب‌پنل ایران ارتباط برقرار کرده و آخرین لیست تانل‌ها را دریافت می‌کند.
* **اجرای خودکار پروسه‌ها:**
  اگر در پنل وب ایران تانل جدیدی بسازید یا پورت آن را ویرایش کنید، ایجنت به صورت آنی پروسه‌های تانل را ایجاد، بروزرسانی یا ری‌استارت می‌کند.

---

### ۲. نیازمندی‌های فایروال سرور خارج (Firewall Requirements)

برای اینکه ارتباط تانل بین ایران و سرور خارج بدون وقفه برقرار باشد:

1. **پورت‌های رله تانل (Tunnel Core Ports):**
   * مانند پورت `3095` (تانل سابسکریپشن) یا `3101` (تانل ترافیک VLESS).
   * این پورت‌ها باید در فایروال ابری سرور خارج (Hetzer / DigitalOcean / Cloud Security Group / UFW) به صورت **Inbound TCP** باز باشند تا سرور ایران بتواند با هندشیک امن TLS 1.3 به آن‌ها متصل شود.
2. **پورت‌های اختصاصی سرویس‌های محلی (Local Targets):**
   * مانند پورت `2096` (پنل سابسکریپشن 3X-UI) یا پورت `2087 / 2088` (ورودی هسته Xray).
   * این پورت‌ها صرفاً در داخل خود سرور خارج به صورت لوکال هاست (`127.0.0.1`) شنود می‌شوند و تانل هَوال بسته‌ها را مستقیماً به آن‌ها تحویل می‌دهد؛ بنابراین نیازی نیست این پورت‌ها از بیرون سرور خارج در دسترس عموم باشند.

---

### ۳. جعبه‌ابزار دستورات خط فرمان (`hawal` CLI)

روی سرور نود خارج، می‌توانید با دستورات زیر در کسری از ثانیه وضعیت را پایش کنید:

* **مشاهده پروسه‌ها و وضعیت تانل‌های فعال روی نود:**
  ```bash
  hawal tunnels
  ```
* **سنجش زنده تاخیر (Latency) و سلامت ارتباط با پنل ایران:**
  ```bash
  hawal ping
  ```
* **مشاهده استریم زنده لاگ‌های ایجنت:**
  ```bash
  hawal logs
  ```
* **نمایش مشخصات نود و توکن:**
  ```bash
  hawal info
  ```
* **ری‌استارت تمیز ایجنت و تانل‌ها در صورت بروز نوسان شبکه:**
  ```bash
  hawal restart
  ```
* **باز کردن منوی تعاملی و مانیتورینگ زنده:**
  ```bash
  hawal
  ```

### ۴. چک‌لیست عیب‌یابی سریع (Troubleshooting)

| علائم مشکل | دلیل محتمل | راه‌حل سریع |
| :--- | :--- | :--- |
| **نود در پنل «آفلاین» است** | وقفه اینترنت بین‌الملل یا بسته بودن پورت ۹۰۹۰ در سمت ایران | اجرای `hawal ping` روی سرور خارج برای بررسی برقراری سوکت به پورت ۹۰۹۰ ایران |
| **خطای `i/o timeout` در تانل** | بسته بودن پورت رله در فایروال سرور خارج | باز کردن پورت رله (مثلاً ۳۰۹۵ یا ۳۱۰۱) در فایروال پرووایدر سرور خارج |
| **تداخل در پروسه‌های قدیمی** | وجود پروسه یتیم روی پورت | اجرای دستور `hawal restart` جهت پاکسازی تمام پردازش‌های منسوخ |
